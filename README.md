DNA Detectives is an interactive educational game that introduces players to basic bioinformatics concepts through a DNA investigation.

About the Project

Players take on the role of DNA detectives, investigating DNA sequences, identifying genetic differences, and evaluating evidence related to antibiotic resistance. The game transforms scientific concepts into an engaging, detective-style experience.

Features

DNA Sequence Comparison: Compare a reference DNA sequence with a sample to identify differences.

Mutation Detection: Identify changes in DNA nucleotides.

Evidence Analysis: Evaluate whether the available evidence supports a link between a DNA change and antibiotic resistance.

Interactive Gameplay: Learn basic scientific concepts through an investigation-based game.

Connection to Bioinformatics

Bioinformatics combines biology, computer science, and data analysis to study biological information. DNA Detectives introduces simplified concepts of sequence comparison, genetic variant identification, and biological data interpretation.

The game is designed for educational purposes and does not replace real-world genetic analysis or laboratory testing.

How to Play

Open the game in a web browser.

Read the investigation clues and instructions.

Compare the reference DNA sequence with the sample.

Identify the differences between the sequences.

Analyse the evidence and select the most appropriate conclusion.
